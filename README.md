# .github – organization defaults for tribhushan

Holds the **issue forms** and the **pull request template** used by every repository in this organization.
Public by GitHub's design (default community-health files must live in a public `.github` repo) –
it contains only templates: **no code, no secrets, no personal data**.

| Form | Issue type |
|---|---|
| Feature | user story with acceptance criteria |
| Task | technical work |
| Bug | defect with environment and severity |
| Incident | production problem (S1–S4) |
| Change request | standard / normal / emergency, risk, test, rollback |
| Request | routine need |
| Spike | timeboxed research |
| Idea | for later |
| Risk | risk register entry (likelihood × impact) |
